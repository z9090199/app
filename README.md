# میرا والٹ v2 — Add Money + Withdraw + Admin Panel

نئے features:
- **رقم شامل کریں (Add Money):** صارف JazzCash / Easypaisa / SadaPay چنتا ہے → آپ کا اکاؤنٹ نمبر دیکھ کر رقم بھیجتا ہے → Transaction ID کے ساتھ درخواست جمع کراتا ہے
- **رقم نکالیں (Withdraw):** صارف اپنا اکاؤنٹ نمبر دے کر درخواست بھیجتا ہے
- **Admin Panel:** مالک کو تمام pending درخواستیں نظر آتی ہیں — منظور کرنے پر بیلنس خود بدل جاتا ہے
- ہر نئی درخواست پر terminal میں 🔔 ADMIN ALERT (اور smtp mode میں مالک کو ای میل بھی)

## پہلے یہ سیٹنگز بدلیں (app.py سب سے اوپر)

1. `ADMIN_MOBILE` — اپنا موبائل نمبر لکھیں۔ اسی نمبر سے سائن اپ/لاگ ان کرنے پر Admin Panel نظر آئے گا
2. `PAYMENT_METHODS` — اپنے اصلی JazzCash / Easypaisa / SadaPay اکاؤنٹ کے نام اور نمبر لکھیں (یہی صارفین کو دکھائے جائیں گے)

## چلانے کا طریقہ

```
pip install -r requirements.txt
python app.py
```
براؤزر: http://localhost:3000

## کام کرنے کا طریقہ

1. صارف "رقم شامل کریں" دبا کر طریقہ چنتا ہے → آپ کا اکاؤنٹ نمبر دیکھ کر (اصل زندگی میں) رقم بھیجتا ہے → رقم اور TID لکھ کر درخواست بھیجتا ہے
2. آپ کو terminal میں 🔔 alert نظر آتا ہے، اور Admin Panel میں درخواست آ جاتی ہے
3. آپ اپنا JazzCash/Easypaisa چیک کر کے تصدیق کرتے ہیں کہ رقم واقعی آئی ہے
4. **منظور کریں** دبائیں → صارف کے والٹ میں بیلنس شامل — یا **مسترد** کریں
5. Withdraw میں الٹا: پہلے آپ صارف کے دیے ہوئے نمبر پر رقم بھیجیں، پھر منظور دبائیں → بیلنس کٹ جائے گا

## ⚠️ نہایت اہم

یہ demo/سیکھنے کا نظام ہے۔ **اصلی پیسوں کے ساتھ عوام کے لیے چلانے سے پہلے** اپنے ملک کے قوانین ضرور معلوم کریں — پاکستان میں عوام سے رقم جمع کر کے والٹ چلانا SBP (اسٹیٹ بینک) کے لائسنس کے بغیر غیر قانونی ہو سکتا ہے۔ دوستوں/فیملی میں سیکھنے کے لیے فرضی رقم کے ساتھ بالکل ٹھیک ہے۔
